# Microsoft Store assets

Everything Partner Center asks for when creating or updating the Store listing.

## Listings

[`listings/`](listings) has one file per language the app ships in, each with the product name, short description, description, release notes, features, keywords, and the copyright, license, privacy and support entries. Copy each section into the matching field of that language's listing.

## Images

All images are in [`images/`](images), generated by `tools/make-store-art.ps1` from the real app captures in `docs/images/`.

| Partner Center field | File | Size |
| --- | --- | --- |
| Screenshots (Desktop) | `screenshot-1-flyout.png`, `screenshot-2-per-channel.png`, `screenshot-3-tray.png` | 1920 × 1080 |
| Store logos: 1:1 box art | `boxart-2160x2160.png` (or `boxart-1080x1080.png`) | 2160 × 2160 |
| Store logos: 2:3 poster art | `poster-1440x2160.png` (or `poster-720x1080.png`) | 1440 × 2160 |
| Store logos: 1:1 app tile icon | `storelogo-300x300.png` | 300 × 300 |
| 16:9 Super hero art | `hero-1920x1080.png` | 1920 × 1080 |

The screenshots are in English; the same images can be used for every language's listing.
