# Store listing: Polski (Polska) (pl-PL)

## Product name
Sonar Flyout

## Short description
Natywny mikser w zasobniku Windows 11 dla SteelSeries Sonar. Zmieniaj głośność i wyjścia kanałów jednym kliknięciem.

## Description
Sonar Flyout udostępnia SteelSeries Sonar jednym kliknięciem. Kliknij ikonę na pasku zadań, aby ustawić kanał główny, grę, czat, multimedia, Aux i mikrofon, wyciszyć dowolny kanał lub przełączyć wszystkie kanały między słuchawkami, głośnikami i innymi urządzeniami, bez otwierania SteelSeries GG.

Wygląda i działa jak panel głośności Windows: projekt Fluent, jasny i ciemny motyw, Twój język oraz obsługa klawiatury i czytników ekranu. Gdy potrzebujesz więcej kontroli, rozłącz wyjścia i kieruj każdy kanał na osobne urządzenie, tak jak przełącznikiem łączenia w Sonar.

Sonar Flyout komunikuje się tylko z SteelSeries GG na Twoim komputerze i nie zbiera żadnych danych.

Wymaga SteelSeries GG z włączonym Sonar w trybie Classic.

Sonar Flyout to niezależny projekt, niepowiązany z SteelSeries ani przez nią niepopierany czy sponsorowany. SteelSeries, SteelSeries GG i SteelSeries Sonar są znakami towarowymi SteelSeries ApS.

## What's new in this version
Przewiń nad ikoną, aby zmienić główną głośność.

## Product features
- Głośność kanału głównego, gry, czatu, multimediów, Aux i mikrofonu z paska zadań
- Wyciszanie i włączanie dźwięku dowolnego kanału jednym kliknięciem
- Natychmiastowe przełączanie wszystkich kanałów na inne urządzenie wyjściowe
- Osobne urządzenie dla każdego kanału
- Wybór mikrofonu używanego przez Sonar
- Ikona pokazuje główną głośność Sonar
- Przewiń nad ikoną, aby zmienić główną głośność
- Ostrzeżenie, gdy Windows nie używa Sonar, i naprawa jednym kliknięciem
- Jasny i ciemny motyw, 13 języków, opcjonalne uruchamianie z Windows
