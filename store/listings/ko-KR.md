# Store listing: 한국어 (대한민국) (ko-KR)

## Product name
Sonar Flyout

## Short description
SteelSeries Sonar용 Windows 11 네이티브 트레이 믹서. 채널 볼륨과 출력을 클릭 한 번으로 바꾸세요.

## Description
Sonar Flyout을 사용하면 SteelSeries Sonar를 클릭 한 번으로 조작할 수 있습니다. 작업 표시줄의 아이콘을 클릭해 마스터, 게임, 채팅, 미디어, Aux, 마이크를 조절하고, 원하는 채널을 음소거하거나, 모든 채널을 헤드폰, 스피커 및 다른 장치로 전환하세요. SteelSeries GG를 열 필요가 없습니다.

모양과 동작이 Windows 자체 볼륨 패널과 같습니다. Fluent 디자인, 밝은 테마와 어두운 테마, 사용자 언어, 키보드 및 화면 읽기 프로그램을 지원합니다. 더 세밀하게 제어하려면 출력 연결을 해제해 각 채널을 별도의 장치로 보내세요. Sonar의 연결 토글과 똑같이 동작합니다.

Sonar Flyout은 PC의 SteelSeries GG와만 통신하며 어떠한 데이터도 수집하지 않습니다.

Classic 모드에서 Sonar가 활성화된 SteelSeries GG가 필요합니다.

Sonar Flyout은 독립 프로젝트이며 SteelSeries와 제휴하거나 SteelSeries의 보증 또는 후원을 받지 않습니다. SteelSeries, SteelSeries GG 및 SteelSeries Sonar는 SteelSeries ApS의 상표입니다.

## What's new in this version
트레이 아이콘 위에서 스크롤하여 마스터 볼륨 조절.

## Product features
- 작업 표시줄에서 마스터, 게임, 채팅, 미디어, Aux, 마이크 볼륨 조절
- 클릭 한 번으로 모든 채널 음소거 및 해제
- 모든 채널을 다른 출력 장치로 즉시 전환
- 채널마다 별도의 장치로 출력
- Sonar가 사용할 마이크 선택
- 트레이 아이콘에 Sonar 마스터 볼륨 표시
- 트레이 아이콘 위에서 스크롤하여 마스터 볼륨 조절
- Windows에서 Sonar를 사용하지 않으면 알려 주고 클릭 한 번으로 해결
- 밝은 테마와 어두운 테마, 13개 언어, Windows 시작 시 실행(선택)
