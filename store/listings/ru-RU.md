# Store listing: Русский (Россия) (ru-RU)

## Product name
Sonar Flyout

## Short description
Нативный микшер в области уведомлений Windows 11 для SteelSeries Sonar. Меняйте громкость и вывод каналов в один клик.

## Description
Sonar Flyout делает SteelSeries Sonar доступным в один клик. Нажмите на значок на панели задач, чтобы настроить общий уровень, игру, чат, медиа, Aux и микрофон, выключить звук любого канала или переключить все каналы между наушниками, колонками и другими устройствами, не открывая SteelSeries GG.

Он выглядит и работает как панель громкости Windows: дизайн Fluent, светлая и тёмная тема, ваш язык, поддержка клавиатуры и экранного диктора. Для большего контроля отвяжите выводы и направляйте каждый канал на своё устройство, как переключателем связи в Sonar.

Sonar Flyout взаимодействует только с SteelSeries GG на вашем компьютере и не собирает никаких данных.

Требуется SteelSeries GG с включённым Sonar в режиме Classic.

Sonar Flyout — независимый проект, не связанный с SteelSeries, не одобренный и не спонсируемый ею. SteelSeries, SteelSeries GG и SteelSeries Sonar являются товарными знаками SteelSeries ApS.

## What's new in this version
Первый выпуск.

## Product features
- Громкость общего канала, игры, чата, медиа, Aux и микрофона прямо с панели задач
- Выключение и включение звука любого канала одним кликом
- Мгновенное переключение всех каналов на другое устройство вывода
- Отдельное устройство для каждого канала
- Выбор микрофона для Sonar
- Значок показывает общую громкость Sonar
- Светлая и тёмная тема, 13 языков, запуск вместе с Windows по желанию
