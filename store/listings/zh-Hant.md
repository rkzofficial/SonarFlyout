# Store listing: 中文(繁體) (zh-Hant)

## Product name
Sonar Flyout

## Short description
適用於 SteelSeries Sonar 的 Windows 11 原生系統匣混音器。一鍵變更各通道音量與輸出。

## Description
Sonar Flyout 讓你一鍵使用 SteelSeries Sonar。按一下工作列中的圖示即可調整主音量、遊戲、聊天、媒體、Aux 和麥克風，將任何通道靜音，或在耳機、喇叭和其他裝置之間切換所有通道，不必開啟 SteelSeries GG。

它的外觀和行為與 Windows 內建的音量面板一致：Fluent 設計、淺色與深色主題、你的語言，以及鍵盤和螢幕助讀程式支援。需要更多控制時，可以取消輸出連結，將每個通道傳送到各自的裝置，就像 Sonar 中的連結切換一樣。

Sonar Flyout 只與你電腦上的 SteelSeries GG 通訊，不會收集任何資料。

需要已在 Classic 模式下啟用 Sonar 的 SteelSeries GG。

Sonar Flyout 是獨立專案，與 SteelSeries 無關，也未獲得 SteelSeries 的認可或贊助。SteelSeries、SteelSeries GG 和 SteelSeries Sonar 是 SteelSeries ApS 的商標。

## What's new in this version
第一個版本。

## Product features
- 從工作列調整主音量、遊戲、聊天、媒體、Aux 和麥克風音量
- 一鍵將任何通道靜音或取消靜音
- 立即將所有通道切換到其他輸出裝置
- 為每個通道指定各自的裝置
- 選擇 Sonar 使用的麥克風
- 系統匣圖示顯示 Sonar 主音量
- 淺色與深色主題、13 種語言、可選擇隨 Windows 啟動
