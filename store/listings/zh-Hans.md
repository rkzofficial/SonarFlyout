# Store listing: 中文(简体) (zh-Hans)

## Product name
Sonar Flyout

## Short description
适用于 SteelSeries Sonar 的 Windows 11 原生托盘混音器。一键更改各通道音量和输出。

## Description
Sonar Flyout 让你一键使用 SteelSeries Sonar。单击任务栏中的图标即可调节主音量、游戏、聊天、媒体、Aux 和麦克风，将任意通道静音，或在耳机、扬声器和其他设备之间切换所有通道，无需打开 SteelSeries GG。

它的外观和行为与 Windows 自带的音量面板一致：Fluent 设计、浅色和深色主题、你的语言，以及键盘和屏幕阅读器支持。需要更多控制时，可以取消输出链接，将每个通道发送到各自的设备，就像 Sonar 中的链接开关一样。

Sonar Flyout 只与你电脑上的 SteelSeries GG 通信，不收集任何数据。

需要已在 Classic 模式下启用 Sonar 的 SteelSeries GG。

Sonar Flyout 是一个独立项目，与 SteelSeries 无关，也未获得 SteelSeries 的认可或赞助。SteelSeries、SteelSeries GG 和 SteelSeries Sonar 是 SteelSeries ApS 的商标。

## What's new in this version
首个版本。

## Product features
- 在任务栏中调节主音量、游戏、聊天、媒体、Aux 和麦克风音量
- 一键将任意通道静音或取消静音
- 立即将所有通道切换到其他输出设备
- 为每个通道单独指定设备
- 选择 Sonar 使用的麦克风
- 托盘图标显示 Sonar 主音量
- 浅色和深色主题、13 种语言、可选随 Windows 启动
