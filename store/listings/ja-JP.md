# Store listing: 日本語 (日本) (ja-JP)

## Product name
Sonar Flyout

## Short description
SteelSeries Sonar 用の Windows 11 ネイティブなタスク トレイ ミキサー。チャンネルの音量と出力をワンクリックで変更できます。

## Description
Sonar Flyout を使えば、SteelSeries Sonar をワンクリックで操作できます。タスク バーのアイコンをクリックして、マスター、ゲーム、チャット、メディア、Aux、マイクの音量を調整したり、任意のチャンネルをミュートしたり、すべてのチャンネルをヘッドホン、スピーカー、その他のデバイスに切り替えたりできます。SteelSeries GG を開く必要はありません。

見た目も動作も Windows の音量パネルと同じです。Fluent デザイン、ライト/ダーク テーマ、お使いの言語、キーボードとスクリーン リーダーに対応しています。さらに細かく制御したい場合は、出力のリンクを解除して、Sonar のリンク切り替えと同じように各チャンネルを個別のデバイスに送れます。

Sonar Flyout は PC 上の SteelSeries GG とのみ通信し、データは一切収集しません。

Sonar を Classic モードで有効にした SteelSeries GG が必要です。

Sonar Flyout は独立したプロジェクトであり、SteelSeries とは提携しておらず、SteelSeries による承認や後援も受けていません。SteelSeries、SteelSeries GG、SteelSeries Sonar は SteelSeries ApS の商標です。

## What's new in this version
最初のリリースです。

## Product features
- マスター、ゲーム、チャット、メディア、Aux、マイクの音量をタスク バーから調整
- 任意のチャンネルをワンクリックでミュート/ミュート解除
- すべてのチャンネルを別の出力デバイスへすぐに切り替え
- チャンネルごとに個別のデバイスへ出力
- Sonar が使うマイクを選択
- トレイ アイコンに Sonar のマスター音量を表示
- トレイ アイコン上でスクロールしてマスター音量を変更
- ライト/ダーク テーマ、13 言語、Windows と同時に起動 (任意)
